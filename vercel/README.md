# Compiler Design Programs Website

Static dark themed website for Lex and Yacc programs.

## Run locally

Open `index.html` with a local server from this folder:

```bash
python3 -m http.server 3000
```

Then visit:

```text
http://localhost:3000
```

## Deploy on Vercel

Use the `vercel` folder as the static site root, or keep the repo root and set the output/static directory to `vercel`.
